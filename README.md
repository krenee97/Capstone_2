# Capstone 2: EmporiUm Sales Territory Analysis

## Project Overview
This project analyzes sales data for EmporiUm, a student bookstore chain selling books, tech gear, and art supplies. The analisis compares performance across two assigned sales territories.

## Sales Territories Analyzed 
- **Territory 1:** Colorado | Mananger: Jim Heck | Region: West
- **Territory 2:** Texas | Mananger: Jeff "Howdy" Richards | Region: South

## Key Findings 
- Colorado consistently outperforms Texas in monthly reveune 
- Technology & Assessories generates the highest reveune in both territories
- Denver is the top performing store in Colorado ($917,471)
- Beaumont is the top performing store in Texas

## Files 
- `krenee_sales_analysis.ipynb` - Main analysis notebook
- `StoreSales .cvs` - Sales transaction data
- `StoreDetail .cvs` - Product location and territory info
- `Products .cvs` - Product information
- `ProductCategories .cvs` - product category data
- `customer_list .cvs` - Customer information
